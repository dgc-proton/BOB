## Git Guidelines

- don’t force any command without approval of everyone else
- don’t use advanced features that mess with file histories (though amend is ok when used properly)
- give descriptive commit messages
- keep commits small & often when possible (or when we remember!)
- use branches & merge changes form origin/main into the branch regularly
